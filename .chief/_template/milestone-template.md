# Milestone Template

When creating a new milestone, copy this structure:

```
milestone-X/
  _contract/
    .gitkeep
  _goal/
    goal.md        # What this milestone achieves
  _plan/
    _todo.md       # Checklist of tasks
  _report/
    .gitkeep
```

## `_goal/goal.md` should contain:

- Clear description of the milestone objective
- Success criteria
- Constraints or limitations
- Dependencies on other milestones (if any)

## `_plan/_todo.md` format:

```md
# TODO List for Milestone X

- [ ] task-1: [description]
- [ ] task-2: [description]
- [ ] task-3: [description]
```

## Task files:

Use `.chief/_template/task-template.md` as the base for each `task-N.md`.
